[R3440-1] World Model reward predictor + 목적함수
  ● RewardHead: models/tssm.py:264-278
    - feat(h,z) → MLP(2층, 256 hidden) → scalar
    - symlog 공간에서 MSE 학습: MSE(pred, symlog(reward))
  ● 총 목적함수: models/tssm.py:579-585
    L_WM = recon_scale × L_recon
         + reward_scale × L_reward
         + cont_scale × L_continue
         + kl_scale × L_KL
  ● ContinueHead: models/tssm.py:281-291 (에피소드 continue 예측)

[R3440-2] Sparse vs Dense reward
  ● 보상 설정: config.py의 ENV_CFG
    - R_KILL_BASE=20, R_WIN=50 등은 event-driven (sparse 성격)
    - R_STEP=-0.001은 time penalty (dense shaping)
  ● K-step 누적: wm_upper_v2.py:420-421
    cum_rew += (gamma^step_in_K) * step_rew

[R3440-7] 행동 공간 구조 (64 logit, mask, entropy)
  ● DiscreteActor: wm_upper_v2.py:39-81
    - feat → MLP(3층) → reshape(B, 8, 8) → 8개 독립 Categorical
    - _apply_defender_mask: 방어드론(idx≥5)은 target[5:8]에 -inf
    - straight-through one-hot sampling
  ● Entropy 합산: wm_upper_v2.py:726-731
    dist = Categorical(logits=masked_logits)  # (B*H, 8, 8)
    entropy = dist.entropy().sum(dim=-1).mean()  # 에이전트 차원 합산

[R3440-8] TSSM 구현 정보
  ● TSSMConfig: models/tssm.py:49-106
    - deter_size=256, n_categoricals=4, n_classes=4 → stoch_dim=16
    - feat_dim = 256 + 16 = 272
    - n_heads=4, n_layers=2, mlp_hidden=256
  ● DynamicsModel: models/tssm.py:221-249
    - CausalTransformer(d_model=256, n_heads=4, n_layers=2)
    - 입력: concat(z, action) → Linear → Transformer
  ● RepresentationModel: models/tssm.py:142-193
    - EntityEncoder → AttentionPool → concat(ctx, h) → MLP → posterior logits
  ● 2-pass teacher forcing: models/tssm.py:488-602

[R3440-9] 진영 편향 통제
  ● Mirror RSA (적군 정책): env/drone_env.py 참조
    - 동일한 하위 제어기, 무작위 상위 정책
  ● 행동 순서 교대: env/drone_env.py 내 step() 메서드
  ● 거울 대칭 초기 배치: env/drone_env.py 내 reset() 메서드

[R3439] PPO+HRL 비교 baseline
  ● PPOHRLTrainer: ppo_hrl_upper.py
    - 동일 환경, 동일 64-dim action, 동일 하위 제어기
    - WM imagination 없이 실제 환경 trajectory로 PPO 학습

[R3437] PPO vs World Model 프레이밍
  → 코드 구조상 명확:
    - WM+HRL (wm_upper_v2.py): WM imagination → Actor-Critic
    - PPO+HRL (ppo_hrl_upper.py): 실제 환경 → PPO
    - 차이는 학습 신호의 출처(imagination vs 실제 환경)
    - 둘 다 Actor-Critic 구조, PPO는 model-free AC의 한 형태
